# Origen de las fotografías

## Catálogo actual

La carpeta `catalogo-2025/` contiene las fotografías extraídas del PDF actual `CATÁLOGO JUAN & LOLA.pdf` aportado para esta revisión. El documento tiene 81 páginas y cada página corresponde a un montaje real identificado por colección y modelo de silla.

Las imágenes del catálogo actual se están guardando como archivos individuales con nombres semánticos, por ejemplo:

- `agua-marina-forja-cruzada.avif`
- `buganvilla-crossback-natural.avif`
- `cartuja-azul-crossback-blanca.avif`
- `empolvado-rosa-napoleon-blanca.avif`
- `marmolado-orbelina.avif`
- `venecia-verde-agua-crossback-marron-ratan.avif`
- `gasa-beig-orbelina.avif`
- `rustica-forja-palillos.avif`

La web debe utilizar estas fotografías individuales para el catálogo, el visor, la galería y las imágenes principales relacionadas con el catálogo. Los antiguos atlas `catalogo-2025-atlas-*.webp` son una solución temporal y deben desaparecer cuando estén incorporadas y validadas las 81 fotografías individuales.

## Material histórico 2021

La carpeta `catalogo-2021/` se conserva únicamente como material histórico y de respaldo. No debe utilizarse para representar el catálogo vigente cuando exista una fotografía equivalente del catálogo actual.

El catálogo 2021 incluye colecciones que ya no aparecen en el documento actual, por lo que no debe alimentar la galería ni los héroes actuales de la web.
